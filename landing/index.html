开始之前

你可能想知道。

lingo 免费吗？

免费使用，并以 MIT 协议开源。你可以查看、修改和分发代码，条款见 MIT License。

需要什么系统？首次如何打开？

当前预览版支持 macOS 13 及以上的 Apple Silicon Mac。下载 ZIP 解压后为 lingo.app，将其拖入“应用程序”即可。安装包尚未经 Apple 公证；如果系统提示无法验证开发者，可确认来源后在“系统设置 → 隐私与安全性”中选择“仍要打开”。

为什么需要辅助功能权限？

lingo 通过 macOS 辅助功能读取其他 App 里选中的文字；读不到时才模拟 ⌘C 并恢复你的剪贴板。请在“系统设置 → 隐私与安全性 → 辅助功能”（部分系统版本叫“设备控制和数据访问”）里允许 lingo，然后重新打开。菜单栏的“取词诊断…”会显示当前授权和最近几次取词的结果。

需要联网或大模型吗？

查单词不需要，直接使用本机的系统词典。翻译句子和文档需要一个翻译服务：任何 OpenAI 兼容接口（默认指向本机 127.0.0.1:3425），或者 Google、DeepL。接口地址、模型与 Key 都在设置里配置。

我的文字会上传吗？

单词查询不会离开你的电脑。翻译句子与文档时，文字只会发送到你自己配置的接口；API Key 存放在 macOS 钥匙串。lingo 没有自己的服务器，也不含统计和追踪脚本。

支持扫描版 PDF 吗？

暂不支持。没有文字层的扫描件会提示无法读取；带文字层的 PDF 可以正常翻译。

关掉窗口后 lingo 去哪了？

默认继续留在菜单栏，保持取词可用。可在设置 → 通用里选择“关闭主窗口时退出”，也可以打开“在 Dock 中显示”。
