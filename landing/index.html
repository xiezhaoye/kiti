小词典，完整的流程

从看到，到看懂，
只要一次选中。

该快的快，该准的准。单词不打扰网络，长句才请出大模型。

01

选中，就弹出。

在浏览器、PDF、聊天窗口里拖选文字、双击单词或按住 Shift 点击，浮层就出现在鼠标旁边，不抢走你当前的焦点。可以设置不取词的 App 黑名单。

⌥D随时开关自动取词
02

词，查词典；句，找翻译。

单词直接读取 macOS 自带的牛津英汉汉英词典，附柯林斯星级、CET、考研等标签，不调用大模型、不用联网。句子和段落则流式翻译，译文逐字出现。

音标 · 美音 / 英音 · 词性 · 例句 · 相关词

03

想细看，点一下。

点击浮层，主窗口打开并显示完整词条；浮层里的单词也能再双击继续查。查过的词、翻译过的文章，都按天记在左边，随时回看。

⌥Q快速查询，回车直达主窗口

就在你读的地方

一张浮层，
刚好够用。

不必复制、不必切换窗口。释义、音标、发音和例句，都在浮层里；需要时再进入主窗口。

  • 美音 / 英音各自配音标和发音按钮
  • 释义里的英文单词可继续双击查询
  • 复制、在主窗口打开，一步到位
  • kiti 自己的窗口里也能这样取词

不止查单词

整句、整篇、整份文档，
一个输入框搞定。

一个输入框，自动分流。

输入单词就查词典，输入句子就翻译，拖入文件就开始翻译文档。中文和英文自动识别方向，需要时手动反向。

文档，分段并发翻译。

支持 txt、md、docx、有文字层的 pdf、rtf 与 html。按段落并发翻译，显示进度，可取消、重译，译文自动缓存，导出为文本。

读给你听。

用系统语音朗读单词和译文，可选英文和中文声音，语速从 0.6× 到 1.4×。查词时美音与英音分别发音。

数据去哪里，自己决定

用你自己的
翻译服务。

kiti 不自带服务器，也不收集你的任何内容。

  • 单词查询完全在本机完成
  • 句子与文档发送到你配置的接口：任意 OpenAI 兼容服务，或 Google、DeepL
  • API Key 存放在 macOS 钥匙串，可单独为大模型设置代理
  • 历史保存在本机，可导出、导入，或指定同步文件夹在多台电脑间合并

开始之前

你可能想知道。

kiti 免费吗？

免费使用，并以 MIT 协议开源。你可以查看、修改和分发代码，条款见 MIT License。

需要什么系统？首次如何打开？

当前预览版支持 macOS 13 及以上的 Apple Silicon Mac。下载 ZIP 后解压，将 kiti.app 拖入“应用程序”。安装包尚未经 Apple 公证；如果系统提示无法验证开发者，可确认来源后在“系统设置 → 隐私与安全性”中选择“仍要打开”。

为什么需要辅助功能权限？

kiti 通过 macOS 辅助功能读取其他 App 里选中的文字；读不到时才模拟 ⌘C 并恢复你的剪贴板。请在“系统设置 → 隐私与安全性 → 辅助功能”（部分系统版本叫“设备控制和数据访问”）里允许 kiti，然后重新打开。菜单栏的“取词诊断…”会显示当前授权和最近几次取词的结果。

需要联网或大模型吗？

查单词不需要，直接使用本机的系统词典。翻译句子和文档需要一个翻译服务：任何 OpenAI 兼容接口（默认指向本机 127.0.0.1:3425），或者 Google、DeepL。接口地址、模型与 Key 都在设置里配置。

我的文字会上传吗？

单词查询不会离开你的电脑。翻译句子与文档时，文字只会发送到你自己配置的接口；API Key 存放在 macOS 钥匙串。kiti 没有自己的服务器，也不含统计和追踪脚本。

支持扫描版 PDF 吗？

暂不支持。没有文字层的扫描件会提示无法读取；带文字层的 PDF 可以正常翻译。

关掉窗口后 kiti 去哪了？

默认继续留在菜单栏，保持取词可用。可在设置 → 通用里选择“关闭主窗口时退出”，也可以打开“在 Dock 中显示”。
